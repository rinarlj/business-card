My Personal Business Card

This project is a personal business card created as part of Practice Session #1.

The exercise focuses on practicing Git and GitHub (repository initialization, commits, .gitignore, branching, and merging)


This project is based on the business card template created by Jill-Jênn Vie https://github.com/jilljenn/business-card

### My Modifications

I adapted the original business card template by:

- Adding my own personal information
- Creating a custom logo/avatar
- Practicing git branching/merging with the `new_logo` branch

### Requirements
- XeLaTeX
- TeX Live (or another LaTeX distribution)
- Gill Sans font, if using the original configuration
  
### Build
To compile the business card:
`xelatex card.tex`
